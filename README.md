# Gradient Generator

A small frontend tool for creating CSS gradients visually and copying the generated CSS.

## Goal

Make gradient creation quick and understandable without writing CSS by hand.

## Current features

- Choose two gradient colors
- Edit color values with hex inputs
- Adjust gradient angle
- See a live preview
- Copy the generated CSS

## Tech

- HTML
- CSS
- JavaScript

## AI-assisted development

This project is being developed with an AI coding assistant as part of the Frontend AI Engineering track. AI suggestions are reviewed before changes are kept.

## Development conventions

- Keep changes small and focused.
- Prefer accessible, semantic HTML.
- Keep JavaScript simple and readable.
