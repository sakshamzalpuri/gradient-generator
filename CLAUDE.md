# Gradient Generator — AI Coding Context

## Stack

- HTML
- CSS
- JavaScript

## Conventions

- Keep changes small and focused.
- Prefer semantic, accessible HTML.
- Use clear names for IDs, classes, and functions.
- Keep browser JavaScript dependency-free unless a dependency is justified.
- Avoid unnecessary abstractions for this small project.
- Use Conventional Commits.

## Product principles

- The gradient preview is the primary interaction.
- Controls should be easy to understand.
- Generated CSS should be accurate and easy to copy.
- AI-generated changes must be reviewed before they are kept.
